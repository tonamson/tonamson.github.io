Thứ tự dùng

  1. Nén RTK + Headroom + Caveman. Nén shell output, context, và prose agent. Đừng đổ rác vào model.
  2. Đọc Serena + Code Review Graph. Đọc code theo symbol và graph, không grep mù cả repo.
  3. Quy trình Superpowers. Ép workflow: nghĩ, plan, implement, review. Không nhảy code bừa.
  4. Cắt Ponytail. Cắt over-engineering. YAGNI trước khi viết thêm layer.
  5. Taste Tasteskill. Khi đụng UI/landing: design read + dial, anti-slop frontend.

Thứ tự gợi ý: RTK + Caveman + Headroom trước (tiết token), rồi Serena / Graph (đọc code), rồi Superpowers + Ponytail + Tasteskill (process / quality / UI).

Bộ tool

Mỗi cái một việc. Gộp lại thì vibe code đỡ kiểu “AI viết 500 dòng cho 5 dòng”.

RTK

Token · CLI proxy

Rust Token Killer - CLI proxy nén output lệnh dev (git, ls, test log…) trước khi nhét vào context agent. Thường tiết kiệm khoảng 60-90% token trên lệnh phổ biến, binary không dependency.

Khi nào Agent hay chạy shell và log dài làm đầy context.

github.com/rtk-ai/rtk

Headroom

Context compression

Lớp nén context: tool output, log, file, RAG chunk - trước khi tới LLM. Có dạng library / proxy / MCP. Giữ tín hiệu, bỏ phần lặp và noise.

Khi nào Session dài, nhiều tool call, JSON/log phình to.

github.com/headroomlabs-ai/headroom

Serena

MCP · IDE for agents

MCP toolkit semantic: retrieval, edit, refactor theo symbol (LSP), không chỉ đọc file theo dòng. Biến LLM thành agent làm việc trực tiếp trên codebase như có IDE.

Khi nào Cần rename, find ref, nhảy symbol, refactor có cấu trúc.

github.com/oraios/serena

Code Review Graph

MCP · code graph

Local-first graph của repo (Tree-sitter): function, call, import, blast radius. Agent query graph trước khi Grep/Read cả cây - review và explore rẻ token hơn nhiều.

Khi nào Review PR, impact analysis, “ai gọi function này”, large repo.

github.com/tirth8205/code-review-graph

Superpowers

Skills · methodology

Framework skill cho coding agent: brainstorm, plan, TDD/implement, review. Ép agent dùng skill đúng lúc thay vì nhảy thẳng vào “viết code hộ”.

Khi nào Feature lớn, cần kỷ luật process, không one-shot bừa.

github.com/obra/superpowers

Ponytail

Skill · less code

“Laziest senior dev”: hỏi có cần code không, ưu tiên stdlib / native, YAGNI cứng. Benchmark: ít code hơn rõ (thường ~50%+, case over-build tới ~90%), vẫn giữ check an toàn.

Khi nào Agent thích thêm framework, abstraction, dashboard cho việc 10 dòng.

github.com/DietrichGebert/ponytail

Caveman

Skill · terse prose

Ultra-compressed communication: agent nói ngắn như caveman, bỏ filler/hedging, giữ nguyên code, lệnh, error string. Đo khoảng 65% ít token output; có lite / full / ultra (và wenyan). Kèm compress file memory (CLAUDE.md…) để giảm input token mỗi session.

Khi nào Chat dài, context chật, muốn answer gọn nhưng technical vẫn đủ.

github.com/JuliusBrussee/caveman

Tasteskill

Skill · frontend taste

design-taste-frontend: anti-slop cho landing / portfolio. Design read, dials (variance / motion / density), pre-flight chặn pattern AI (Inter default, purple glow, 3 card đều…).

Khi nào UI, redesign, page cá nhân - cần nhìn “người làm”, không “AI template”.

tasteskill.dev

Vibe code không phải tắt não

Vibe là tốc độ và flow. Stack này để agent được dẫn: context gọn (RTK, Headroom, Caveman), code map (Serena, Graph), process (Superpowers), tối giản (Ponytail), UI có critic (Tasteskill).

Còn ship hay không, vẫn là người review diff - và nhớ: 12 năm kinh nghiệm không bằng 1 giờ fix bug của người khác.
