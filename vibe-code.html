01 // EXECUTION PIPELINE

Quy trình 5 bước

Pipeline kỷ luật để giữ token window của agent luôn trong sạch, đọc code đúng chỗ và không over-engineer.

  1. 1. Nén Output & Context PIPELINE.01
    RTK + Headroom + Caveman: Nén output shell command (git, npm, ls), lọc nhiễu JSON payload và rút gọn văn bản phản hồi. Giữ token window sạch cho những tác vụ quan trọng.
  2. 2. Đọc Hiểu Bằng Graph & Symbol PIPELINE.02
    Serena + Code Review Graph: Truy vấn AST và knowledge graph. Định vị chính xác symbol, caller/callee path thay vì grep mù quáng toàn bộ repository.
  3. 3. Kỷ Luật Quy Trình Từng Bước PIPELINE.03
    Superpowers: Thiết lập chu trình nghiêm ngặt: Brainstorming → Implementation Plan → TDD (viết test trước) → Verification độc lập trước khi hoàn thành.
  4. 4. Triệt Tiêu Over-Engineering PIPELINE.04
    Ponytail: Tư duy Senior lười biếng thông minh: YAGNI triệt để, ưu tiên Native API / Web Standards, loại bỏ mọi abstraction và dependency thừa thãi.
  5. 5. Tinh Chỉnh Thẩm Mỹ & Craft PIPELINE.05
    Tasteskill (ui-ux-pro-max): Định hình visual direction, điều chỉnh dials (variance, motion, density) để tạo ra sản phẩm hoàn thiện sắc sảo, chống mọi kiểu AI-slop.
02 // ONE-SHOT SCRIPTS

Cài đặt nhanh

Các lệnh thực thi chính thức. Nhấp nút Copy để copy trực tiếp vào terminal của bạn.

  • RTK (Rust Token Killer)

    -60% to -90% shell tokens docs ↗ 
    # Cài đặt qua Homebrew hoặc curl script
brew install rtk
# curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh

# Kích hoạt hook toàn cục
rtk init -g

  • Headroom

    Context Proxy docs ↗ 
    uv tool install --python 3.13 "headroom-ai[all]"
# hoặc: pip install "headroom-ai[all]"

headroom wrap claude
# headroom wrap cursor | codex | aider …

  • Caveman

    -65% output tokens docs ↗ 
    # macOS / Linux / WSL — cài tự động cho tất cả agent
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash

# Bật mode cô đọng: /caveman  ·  Tắt: normal mode

  • Serena

    LSP Semantic AST docs ↗ 
    # Cần uv: https://docs.astral.sh/uv/
uv tool install -p 3.13 serena-agent
serena init

# MCP server sẵn sàng kết nối vào Claude Code / Cursor / Windsurf

  • Code Review Graph

    Tree-Sitter Graph docs ↗ 
    pip install code-review-graph
# hoặc: uv tool install code-review-graph

code-review-graph install
code-review-graph build

  • Superpowers

    Discipline Engine docs ↗ 
    # Cài đặt qua Claude Code Plugins Official
/plugin install superpowers@claude-plugins-official

  • Ponytail

    -50% to -90% code bloat docs ↗ 
    # Cài qua marketplace
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail

# Multi-agent: npx skills add DietrichGebert/ponytail

  • Tasteskill (ui-ux-pro-max)

    Anti-AI-Slop tasteskill.dev ↗ 
    npx skills add Leonxlnx/taste-skill

# Cài riêng skill design-taste-frontend
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
⚡ Thứ tự thiết lập vàng: Cài RTK + Caveman + Headroom trước để tiết kiệm token, sau đó cài Serena / Graph để hiểu code theo cấu trúc, và hoàn tất với Superpowers + Ponytail + Tasteskill để quản lý quy trình, chất lượng và thẩm mỹ frontend.
03 // TOOL DEEP DIVE

Bộ công cụ chuyên sâu

Mỗi công cụ là một vũ khí sắc bén giải quyết triệt để từng điểm nghẽn của LLM khi viết code thực tế.

RTK

TOKEN KILLER // CLI PROXY

Rust Token Killer — CLI proxy thông minh chặn đứng tình trạng phình token khi agent chạy lệnh shell. Nén git diff, npm test, log build thành dạng tóm tắt cô đọng nhất trước khi đưa vào context window của model.

KHI NÀO DÙNG: Agent liên tục thực thi command line và sinh log dài dòng gây tràn token.

github.com/rtk-ai/rtk

Headroom

CONTEXT COMPRESSION // PROXY

Bộ lọc nén context theo thời gian thực: lọc bớt các đoạn JSON dài, log hệ thống, RAG chunk thừa trước khi gửi đến model. Giữ trọn vẹn tín hiệu kỹ thuật quan trọng và loại bỏ 100% rác dư thừa.

KHI NÀO DÙNG: Phiên làm việc kéo dài, nhiều lượt gọi tool call liên tiếp làm đầy bộ nhớ context.

github.com/headroomlabs-ai/headroom

Caveman

TERSE PROSE // TOKEN SAVER

Rút gọn văn phong giao tiếp của AI về mức tối giản tuyệt đối (caveman style), loại bỏ hoàn toàn các câu mở bài/kết bài sáo rỗng, trong khi giữ nguyên 100% độ chính xác của mã nguồn, lệnh command và thông báo lỗi.

KHI NÀO DÙNG: Muốn agent phản hồi tức thì, không rườm rà, tập trung vào code thay vì văn bản.

github.com/JuliusBrussee/caveman

Serena

MCP // SEMANTIC LSP IDE

Bộ công cụ MCP cấp độ LSP: tìm kiếm, chỉnh sửa và tái cấu trúc code theo symbol ngữ nghĩa (functions, classes, types), không đơn thuần đọc file thô từng dòng. Biến AI model thành lập trình viên thao tác trực tiếp trên IDE.

KHI NÀO DÙNG: Cần rename symbol an toàn, find references, nhảy đến định nghĩa hàm trong codebase lớn.

github.com/oraios/serena

Code Review Graph

MCP // KNOWLEDGE GRAPH

Xây dựng đồ thị cục bộ (Tree-sitter) thể hiện quan hệ gọi hàm, import và vùng ảnh hưởng (blast radius). Agent truy vấn graph nhanh trước khi phải đọc toàn bộ cây thư mục, giúp review PR và trace bug nhanh gấp nhiều lần.

KHI NÀO DÙNG: Review PR phức tạp, đánh giá rủi ro thay đổi hàm lõi, phân tích kiến trúc dự án.

github.com/tirth8205/code-review-graph

Superpowers

FRAMEWORK // METHODOLOGY

Bộ quy tắc kỹ thuật nghiêm ngặt: buộc agent phải trải qua các bước brainstorming, lập kế hoạch chi tiết, TDD và review độc lập. Ngăn chặn tuyệt đối việc AI code ẩu hoặc one-shot thiếu kiểm soát.

KHI NÀO DÙNG: Xây dựng feature lớn, cần tính kỷ luật cao và kiểm thử hoàn chỉnh trước khi merge.

github.com/obra/superpowers

Ponytail

LESS CODE // YAGNI DISCIPLINE

Áp dụng triệt để nguyên lý YAGNI (You Aren't Gonna Need It): đặt câu hỏi phản biện xem có cần viết thêm dòng code nào không, ưu tiên stdlib / native APIs. Giảm 50% – 90% lượng mã dư thừa.

KHI NÀO DÙNG: AI có dấu hiệu tạo boilerplate phức tạp, thêm library không cần thiết cho logic đơn giản.

github.com/DietrichGebert/ponytail

Tasteskill

FRONTEND // TASTE & CRAFT

Kỹ năng frontend chống "AI-slop": điều chỉnh design read, tinh chỉnh các thanh trượt dials (variance / motion / density), đảm bảo mọi giao diện web đều mang tính nghệ thuật, đậm chất craft và phá cách.

KHI NÀO DÙNG: Xây dựng landing page, portfolio cá nhân, web app cần tính thẩm mỹ vượt trội.

tasteskill.dev
04 // CORE PHILOSOPHY

Vibe code không phải là tắt não

Vibe là tốc độ, khả năng làm chủ công cụ và sự liền mạch trong luồng tư duy. Bộ stack này giúp agent được dẫn dắt chính xác: context luôn tinh gọn (RTK, Headroom, Caveman), bản đồ code rõ ràng (Serena, Graph), kỷ luật quy trình (Superpowers), tối giản cấu trúc (Ponytail), và mắt nhìn thiết kế sắc nét (Tasteskill).

Quyết định ship sản phẩm cuối cùng vẫn luôn thuộc về người lập trình viên review diff — và hãy luôn nhớ: "Kinh nghiệm 12 năm lập trình không bằng 1 giờ fix bug của người khác."
